# 🧠 MindSafe 3.1.1

Aplicación web enfocada en la **seguridad mental y el bienestar digital**, desarrollada con **HTML, CSS y JavaScript** y desplegada en **Vercel**.

## 🚀 Características principales

* 🖥️ Interfaz ligera, moderna y responsiva en HTML/CSS.
* ⚡ Funcionalidades interactivas desarrolladas con JavaScript.
* ☁️ Despliegue rápido y gratuito mediante Vercel.
* 🔓 Código abierto para aprendizaje y colaboración.

## 📂 Estructura del proyecto

```text
MindSafe_3.1.1/
├── index.html      # Página principal
├── chat.js         # Lógica de interacción
└── README.md       # Documentación del proyecto
```

## ⚙️ Instalación y uso

### 1. Clonar el repositorio

```bash
git clone https://github.com/aldairHub/MindSafe_3.1.1.git
```

### 2. Acceder al proyecto

```bash
cd MindSafe_3.1.1
```

### 3. Ejecutar la aplicación

Abre el archivo `index.html` directamente en tu navegador.

> 💡 No es necesario instalar dependencias adicionales para ejecutar la versión básica del proyecto.
